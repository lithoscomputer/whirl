# Copies of Stagehand's eval pages

These pages come from Stagehand's eval sites
(`https://browserbase.github.io/stagehand-eval-sites/sites/`), retrieved on
2026-09-26. Several are saved copies of third-party websites: Amazon, Google,
Google Flights, IonWave, a pizza-ordering page, a license-lookup page, and a
checkbox form. They are kept here only to evaluate ACT, under fair use, so the
tasks run against the same pages as Stagehand's `act` evals without the
network. The copies carry no license from Browserbase or the sites' owners.

Changes from the originals:

- `google/index.html` searches to the relative `openai.html` instead of the
  absolute Stagehand URL.
- `ionwave/index.html` links to the relative `closed-bids.html` instead of the
  absolute Stagehand URL.

Do not edit the pages otherwise; a task compares models on them as they were.
